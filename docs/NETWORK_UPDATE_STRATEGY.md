# Internal Network Update Strategy for BOM Management Framework

**Date**: October 30, 2025  
**Environment**: Corporate Network (No Internet/Air-gapped)  
**Update Source**: Local Network Share

---

## Overview

Since your app runs **fully local within your work environment**, you can configure electron-updater to check a **network share** instead of GitHub. This is ideal for:

✅ Air-gapped environments  
✅ Corporate networks without internet  
✅ Internal-only tools  
✅ Controlled update distribution  
✅ Compliance/security requirements  

---

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│            Network File Share (Update Server)                │
│          \\company-server\shared\bom-updates\                │
│                                                               │
│  latest.yml                    ← Metadata file               │
│  BOM-Management-Framework-Setup-1.0.0.exe                    │
│  BOM-Management-Framework-Setup-1.1.0.exe                    │
│  BOM-Management-Framework-1.0.0.AppImage                     │
│  BOM-Management-Framework-1.1.0.AppImage                     │
└─────────────────────────────────────────────────────────────┘
                              ↓
              All users' machines can access this share
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                   User's Desktop App                         │
│                                                               │
│  On Startup → Checks \\company-server\shared\bom-updates\    │
│            → Reads latest.yml                                 │
│            → Compares version                                 │
│            → If newer: "Update available!"                    │
│            → Downloads from network share                     │
│            → Installs on restart                              │
└─────────────────────────────────────────────────────────────┘
```

## Implementation

### Option 1: Generic Provider (Network Share) ⭐ Recommended

This is the simplest approach - electron-updater reads from a network path or local HTTP server.

#### 1. Update `package.json` Build Config

```json
{
  "build": {
    "appId": "com.company.bom-management-framework",
    "productName": "BOM Management Framework",
    "publish": {
      "provider": "generic",
      "url": "file://company-server/shared/bom-updates",
      // Or use UNC path:
      // "url": "file:////company-server/shared/bom-updates"
      // Or use mapped drive:
      // "url": "file://Z:/bom-updates"
    },
    // ... rest of config
  }
}
```

#### 2. Update `electron.js` - Same Code!

The auto-updater code remains **exactly the same** - electron-updater automatically uses the generic provider:

```javascript
const { autoUpdater } = require('electron-updater')
const log = require('electron-log')

// Configure
autoUpdater.logger = log
autoUpdater.autoDownload = false

// Check for updates
app.on('ready', () => {
  setTimeout(() => {
    if (!isDev) {
      autoUpdater.checkForUpdates()
    }
  }, 3000)
})

// Same event handlers as before
autoUpdater.on('update-available', (info) => {
  dialog.showMessageBox(mainWindow, {
    type: 'info',
    title: 'Update Available',
    message: `Version ${info.version} is available on the network.`,
    detail: 'Download from internal update server?',
    buttons: ['Download', 'Later']
  }).then((result) => {
    if (result.response === 0) {
      autoUpdater.downloadUpdate()
    }
  })
})

autoUpdater.on('update-downloaded', (info) => {
  dialog.showMessageBox(mainWindow, {
    type: 'info',
    title: 'Update Ready',
    message: 'Restart to apply update?',
    buttons: ['Restart Now', 'Later']
  }).then((result) => {
    if (result.response === 0) {
      autoUpdater.quitAndInstall()
    }
  })
})
```

#### 3. Network Share Structure

Your network share should look like this:

```
\\company-server\shared\bom-updates\
├── latest.yml                              ← Generated by electron-builder
├── BOM-Management-Framework-Setup-1.0.0.exe
├── BOM-Management-Framework-Setup-1.1.0.exe
└── BOM-Management-Framework-Setup-1.2.0.exe
```

### Option 2: Local HTTP Server on Network

If file:// URLs don't work (some corporate networks), run a simple HTTP server:

#### Setup Simple HTTP Server

**Using Python** (built into Windows 10+):
```bash
# On the server/shared machine
cd \\company-server\shared\bom-updates
python -m http.server 8080
```

**Using Node.js**:
```bash
npm install -g http-server
http-server \\company-server\shared\bom-updates -p 8080
```

**Using IIS** (Windows Server):
1. Install IIS with Static Content
2. Create website pointing to update folder
3. Set port 8080
4. Done!

#### Update `package.json`

```json
{
  "build": {
    "publish": {
      "provider": "generic",
      "url": "http://company-server:8080"
      // Or use IP: "http://192.168.1.100:8080"
    }
  }
}
```

### Option 3: Environment-Based Configuration

If you want **different update sources** for different environments (dev, staging, production):

#### Create `electron-builder.env.js`

```javascript
// electron-builder.env.js
module.exports = {
  development: {
    provider: 'generic',
    url: 'file://localhost/updates'  // Local testing
  },
  staging: {
    provider: 'generic',
    url: 'file://staging-server/shared/bom-updates'
  },
  production: {
    provider: 'generic',
    url: 'file://company-server/shared/bom-updates'
  }
}
```

#### Update `electron.js`

```javascript
const { autoUpdater } = require('electron-updater')

// Override update URL at runtime
if (!isDev) {
  const updateServerUrl = process.env.UPDATE_SERVER_URL || 'file://company-server/shared/bom-updates'
  autoUpdater.setFeedURL({
    provider: 'generic',
    url: updateServerUrl
  })
}

autoUpdater.checkForUpdates()
```

#### Set Environment Variable

```bash
# In production deployment
$env:UPDATE_SERVER_URL="file://company-server/shared/bom-updates"
```

## Release Workflow (Internal Network)

### Step 1: Build New Version

```bash
# Update version
npm version patch  # 1.0.0 → 1.0.1

# Build for distribution
npm run build
npm run electron-pack-win
```

This creates:
- `dist/BOM-Management-Framework-Setup-1.0.1.exe`
- `dist/latest.yml`

### Step 2: Copy to Network Share

**Manual** (simple):
```powershell
# Copy new files to network share
Copy-Item "dist\BOM-Management-Framework-Setup-1.0.1.exe" "\\company-server\shared\bom-updates\"
Copy-Item "dist\latest.yml" "\\company-server\shared\bom-updates\"
```

**Automated** (add to package.json):
```json
{
  "scripts": {
    "deploy-internal": "npm run build && npm run electron-pack-win && node scripts/deploy-to-network.js"
  }
}
```

**scripts/deploy-to-network.js**:
```javascript
const fs = require('fs')
const path = require('path')

const NETWORK_SHARE = '\\\\company-server\\shared\\bom-updates'
const distFolder = path.join(__dirname, '../dist')

// Copy installer and metadata
fs.copyFileSync(
  path.join(distFolder, 'latest.yml'),
  path.join(NETWORK_SHARE, 'latest.yml')
)

// Find .exe file
const files = fs.readdirSync(distFolder)
const exeFile = files.find(f => f.endsWith('.exe'))

if (exeFile) {
  fs.copyFileSync(
    path.join(distFolder, exeFile),
    path.join(NETWORK_SHARE, exeFile)
  )
  console.log(`✅ Deployed ${exeFile} to network share`)
} else {
  console.error('❌ No .exe file found in dist/')
}
```

### Step 3: Users Get Update Automatically

Next time any user opens the app:
1. App checks `\\company-server\shared\bom-updates\latest.yml`
2. Compares version
3. Shows update prompt if newer version exists
4. Downloads from network share (fast local network speed!)
5. Installs on restart

## Permissions & Security

### Network Share Permissions

**Minimum required**:
```
READ access for all users
WRITE access for IT/release manager only
```

**Windows Share Setup**:
```powershell
# Create share
New-SmbShare -Name "bom-updates" -Path "C:\Shares\bom-updates" -ReadAccess "Domain Users" -ChangeAccess "IT-Admins"

# Set NTFS permissions
icacls "C:\Shares\bom-updates" /grant "Domain Users:(RX)" /T
icacls "C:\Shares\bom-updates" /grant "IT-Admins:(F)" /T
```

### Firewall Rules

If using HTTP server:
```powershell
# Allow inbound on port 8080
New-NetFirewallRule -DisplayName "BOM Updates Server" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
```

## Troubleshooting

### Issue: "Cannot access network path"

**Cause**: File permissions or UNC path syntax

**Fix**:
```javascript
// Try different URL formats:
"url": "file://company-server/shared/bom-updates"           // Basic
"url": "file:////company-server/shared/bom-updates"         // UNC (4 slashes)
"url": "file://Z:/bom-updates"                              // Mapped drive
"url": "http://company-server:8080"                         // HTTP fallback
```

### Issue: "Update check fails silently"

**Cause**: Missing or invalid `latest.yml`

**Fix**: Ensure electron-builder generates it:
```bash
npm run electron-pack-win  # Always generates latest.yml
```

### Issue: "Download is slow"

**Cause**: Network share performance

**Fix**: Use local HTTP server instead of file:// URLs

### Issue: "Update doesn't install"

**Cause**: App doesn't have write permissions

**Fix**: Run installer with admin rights, or install to user directory:
```json
{
  "build": {
    "nsis": {
      "perMachine": false,  // Install per-user (no admin needed)
      "allowToChangeInstallationDirectory": true
    }
  }
}
```

## Best Practices

### 1. Keep Old Versions

Don't delete old installers - users may need to downgrade:

```
\\company-server\shared\bom-updates\
├── latest.yml                              ← Always points to newest
├── archive/
│   ├── BOM-Management-Framework-Setup-1.0.0.exe
│   └── BOM-Management-Framework-Setup-1.0.1.exe
└── BOM-Management-Framework-Setup-1.0.2.exe  ← Latest
```

### 2. Release Notes

Add release notes to network share:

```
\\company-server\shared\bom-updates\
├── latest.yml
├── RELEASE_NOTES.md
└── BOM-Management-Framework-Setup-1.0.2.exe
```

Read in app:
```javascript
autoUpdater.on('update-available', async (info) => {
  const releaseNotesPath = '\\\\company-server\\shared\\bom-updates\\RELEASE_NOTES.md'
  const notes = fs.readFileSync(releaseNotesPath, 'utf8')
  
  dialog.showMessageBox({
    message: `Version ${info.version} available`,
    detail: notes
  })
})
```

### 3. Backup Database Before Update

```javascript
autoUpdater.on('before-quit-for-update', () => {
  const dbPath = path.join(app.getPath('userData'), 'db/custom.db')
  const backupPath = path.join(app.getPath('userData'), `db/custom.db.backup.${Date.now()}`)
  fs.copyFileSync(dbPath, backupPath)
  log.info('Database backed up before update')
})
```

### 4. Staged Rollout

Test with small group first:

```
\\company-server\shared\bom-updates-beta\    ← Beta testers
\\company-server\shared\bom-updates\         ← Everyone
```

Configure per user:
```javascript
const isBetaTester = ['user1', 'user2'].includes(os.userInfo().username)
const updateUrl = isBetaTester 
  ? 'file://company-server/shared/bom-updates-beta'
  : 'file://company-server/shared/bom-updates'
```

```json
  }
```

### electron.js (Auto-Update Section)

```javascript
const { app, BrowserWindow, dialog } = require('electron')
const { autoUpdater } = require('electron-updater')
const log = require('electron-log')
const isDev = require('electron-is-dev')

// Configure auto-updater
autoUpdater.logger = log
autoUpdater.autoDownload = false
autoUpdater.allowDowngrade = false

// Override update URL if environment variable set
if (process.env.UPDATE_SERVER_URL) {
  autoUpdater.setFeedURL({
    provider: 'generic',
    url: process.env.UPDATE_SERVER_URL
  })
}

app.on('ready', () => {
  createWindow()
  
  // Check for updates after 3 seconds (only in production)
  if (!isDev) {
    setTimeout(() => {
      log.info('Checking for updates from network share...')
      autoUpdater.checkForUpdates()
    }, 3000)
  }
})

// Update event handlers
autoUpdater.on('checking-for-update', () => {
  log.info('Checking for updates...')
})

autoUpdater.on('update-available', (info) => {
  log.info('Update available:', info.version)
  
  dialog.showMessageBox(mainWindow, {
    type: 'info',
    title: 'Update Available',
    message: `Version ${info.version} is available on the network.`,
    detail: 'Would you like to download it now?',
    buttons: ['Download', 'Later'],
    defaultId: 0,
    cancelId: 1
  }).then((result) => {
    if (result.response === 0) {
      autoUpdater.downloadUpdate()
    }
  })
})

autoUpdater.on('update-not-available', (info) => {
  log.info('No updates available. Current version:', info.version)
})

autoUpdater.on('error', (err) => {
  log.error('Auto-updater error:', err)
})

autoUpdater.on('download-progress', (progressObj) => {
  log.info(`Download: ${progressObj.percent.toFixed(2)}%`)
})

autoUpdater.on('update-downloaded', (info) => {
  log.info('Update downloaded:', info.version)
  
  dialog.showMessageBox(mainWindow, {
    type: 'info',
    title: 'Update Ready',
    message: 'Update has been downloaded.',
    detail: 'The application will restart to install the update.',
    buttons: ['Restart Now', 'Later'],
    defaultId: 0,
    cancelId: 1
  }).then((result) => {
    if (result.response === 0) {
      setImmediate(() => autoUpdater.quitAndInstall(false, true))
    }
  })
})
```
